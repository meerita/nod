# PR Review

This skill is disabled.

Do not invoke it for ordinary internally produced Nod work.

Internal work carries its own evidence trail.

`/definition-of-done` audits that evidence.

`/pr-check` owns integration readiness.

Enable this skill only when Nod accepts pull requests that arrive without that evidence trail.
